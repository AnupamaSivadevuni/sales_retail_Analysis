# sales_retail_Analysis

## 📌 Project Overview
This interactive Power BI dashboard analyzes retail sales performance, product category trends, transaction patterns, and regional sales distribution. Developed as part of the **Google Data Analytics / BI Capstone Project**, this report provides actionable business intelligence to optimize inventory planning, evaluate revenue drivers, and understand customer purchasing behavior.

---

## 🎯 Business Objectives & Key Questions
* **Revenue Trends:** What are the historical sales patterns and monthly revenue trajectories?
* **Category Performance:** Which product lines and sub-categories generate the highest profit margins vs. transaction volumes?
* **Regional Insights:** How do sales metrics perform across different geographic territories and store locations?
* **Customer Behavior:** What is the average order value (AOV) and order frequency across key customer segments?

---

## 🛠️ Data Stack & Skills Applied
* **Business Intelligence:** Microsoft Power BI Desktop
* **Data Modeling:** Star Schema architecture, Fact vs. Dimension tables, relationship cardinalities (1:Many)
* **DAX Syntax:** Custom measures using `CALCULATE`, `SUMX`, `DIVIDE`, time-intelligence functions (`SAMEPERIODLASTYEAR`, `YTD`)
* **Data Transformation:** Power Query ETL for cleaning, column parsing, data typing, and null value handling
* **Reporting & UX:** Mobile-responsive layout, bookmark navigation, contextual tooltips, dynamic drill-throughs

---

## 📊 Key Dashboard Features
1. **Executive Overview Page:** High-level KPIs covering Total Sales, Total Profit, Profit Margin %, and Units Sold with Year-Over-Year (YoY) variance.
2. **Category & Product Breakdown:** Visual breakdown of top-performing items and low-margin products requiring inventory adjustments.
3. **Temporal Trend Analysis:** Interactive line charts detailing seasonality and high-volume purchasing windows.
